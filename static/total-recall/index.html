Need a reminder? The three definitions
Recall
Of the items that are actually positive, what fraction did the classifier find?
recall = true positives / actual positives
Precision
Of the items the classifier labeled positive, what fraction really were positive?
precision = true positives / labeled positive
Accuracy
Of all the items, what fraction did the classifier get right? It counts both kinds of correct answers: positives it caught and negatives it left alone.
accuracy = (true positives + true negatives) / total
